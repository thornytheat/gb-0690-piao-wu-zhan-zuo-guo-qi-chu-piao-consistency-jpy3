# 租约与票据定义

id为事件号、order为订单、ticket为票号，字符串保留前导零及超大数字。seat接受A01或A-01并统一A-01，目录A-01至A-16。channel为官方、票社、团购。
show为场次号；多场演出共用同一套座席编号，余票、租约、支付、出票与对账均以(场次,座席)为边界，跨场同号座席互不阻挡。CSV含show列但该行为空（含-、N/A、NULL、未知）时以原因码NO_SHOW隔离，保留来源行号与原始单元格，可追查且不进入任何场次的余票与收入；CSV不含show列时整批回填参数default_show。
time带偏移，统一UTC，回放按事件时间排序，同刻先release再hold再pay再issue。hold需expires且后于time。
占座有效区间[start,end)，到期点付款无效。release仅能释放当前同订单租约，缩短end；其后旧支付不得恢复座席。占用中其他订单hold隔离。
同事件最高version采信，同版相互矛盾全部隔离。重复、旧版、无效状态都有来源行号与原因码。支付每租约只允许一笔，出票需在支付之后且金额相等，票号全场（跨场次）唯一，座席每场唯一。
渠道对账按(场次,渠道)为有效支付减有效出票，金额为Decimal字符串，悬单单独统计，不把它认作丢失事件；另给每场合计。事件原始行序判断补传迟到，水位按场次各自维护，业务仍按事件时间完整回放。
输入行数=采信事件+隔离，租约/支付/票据各为派生集合不替代原始计数。空文件等失败码独立，运行ID含输入哈希、规则版本与参数，复核整数版本递增。

支付渠道须与其占座租约一致，出票渠道须与有效支付一致；跨渠道冲突逐行隔离，不在渠道间静默移动金额。
